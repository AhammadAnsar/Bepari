# Bepari — Human-Centered UX Design Rules
1. **Palette**: Surface `#FAFAF8`, Card `#FFFFFF`, Primary text `#172326`, Secondary text `#5D686D`, Hairline border `#E0E6E2`, Evergreen action `#126B58`, Hover `#0C5345`, Focus `#287A69`, Warning `#A65E13`, Danger `#B42318`.
2. **Typography**: Bengali `Noto Sans Bengali`, English `Plus Jakarta Sans`, Monetary/Codes `JetBrains Mono` with `tabular-nums`.
3. **Anti-AI-Slop Rules**: Zero fabricated KPI numbers, zero decorative gradients or pulsing dots, zero static pill badge clutter, and honest phase-gated empty states.
